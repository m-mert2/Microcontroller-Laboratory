# PIC Assembly Laboratory Projects

This repository contains my PIC Assembly laboratory studies.

microcontroller laboratory course.

## 🔧 Technologies & Environment

- **Microcontroller:** PIC16F877A (8-bit)
- **Architecture:** 8-bit
- **Language:** PIC Assembly
- **Assembler:** MPLAB XC8
- **IDE:** MPLAB X IDE
- **Simulation:** PICSimLab
